Archive and Soft Delete

The archive and the soft delete library are libraries of their own. Titles moved there leave their library on disk and stop showing up next to everything else. They stay one button away on clients that support it, such as Moonfin. Make a library for each first (Dashboard → Libraries), then pick it here. Leave one set to None to switch it off.

Who gets a button and who can see a library are set separately. Somebody can be allowed to soft delete a title without being able to see the soft deleted titles. Bringing a title back needs both the button and access to the library it's in.

Everything

Titles moved through this plugin go back where they came from. This is only for titles put in the archive or the soft delete library some other way.
Each library above is opened to the people allowed to see it and closed to everybody else, in every app. Somebody on "all libraries" who may not see one of them is given every other library instead, including libraries added later, and gets "all libraries" back once they're allowed to see both. Turn this off to manage library access by hand.
